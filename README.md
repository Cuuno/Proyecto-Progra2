Proyecto final Programación 2 - Isdm.

Sistema de un Hospital

Proceso = Admision y Altas de pacientes

Narrativa =

Un paciente con orden médica solicita una internación. Recepción verifica disponibilidad de habitaciones, registra al paciente (en caso de no estar registrado), crea el ingreso (fecha/hora, médico responsable, diagnostico) y asigna la habitación disponible. Luego cuando el paciente es dado de alta, recepción registra la misma con la observación. Recepcion puede registrar pacientes nuevos, admitirlos, consultar pacientes internados actualmente, la disponibildad de habitaciones, el historial del paciente o los pacientes por dni, generar un grafico con el promedio de días de internación por diagnóstico y un grafico de habitaciones ocupadas/libres. Además puede exportar los datos del sistema y restaurarlos.
